# Student Management System

## Introduction

The Student Management System is a simple Python project used to manage basic student records. It allows the user to add, view, search, and delete student information.

The project is created using basic Python programming concepts and is designed as a beginner-level command-line application.

## Features

- Add a new student
- View all student records
- Search for a student using student ID
- Delete a student record
- Store student information in a JSON file
- Basic input validation
- Automated testing

## Technologies Used

- Python 3
- JSON
- Python standard library

No external Python libraries are required.

## Requirements

- Python 3 or above
- A computer with a command prompt or Python IDLE

## Project Files

- `main.py` - Main program and menu
- `student_data.py` - Adds, searches, views, and deletes student records
- `student_display.py` - Displays student information
- `student_utils.py` - Takes and validates student input
- `student_words.py` - Contains basic course information
- `student_reports.py` - Displays student summary information
- `test_project.py` - Tests the main student record functions
- `students.json` - Stores student records
- `statement.md` - Contains the project statement
- `README.md` - Project documentation
